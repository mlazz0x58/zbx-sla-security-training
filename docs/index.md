# Programa Oficial de Capacitação Técnica  
## Segurança em Aplicações Web – Projeto ZBX-SLA

Este portal consolida as diretrizes técnicas estabelecidas após o Web Penetration Test conduzido no sistema ZBX-SLA.

O objetivo é:

- Padronizar práticas seguras de desenvolvimento
- Reduzir recorrência de vulnerabilidades
- Fortalecer maturidade de segurança da equipe
- Integrar segurança ao ciclo de desenvolvimento (Secure SDLC)

---

> Este documento possui caráter preventivo e educativo, não punitivo.
