# Objetivo da Capacitação

Capacitar a equipe técnica no entendimento das vulnerabilidades identificadas durante o Web Penetration Test realizado no sistema **ZBX-SLA**.

A capacitação foca em:

- Consciência de segurança
- Prevenção de recorrência
- Padronização de implementação segura
- Integração com boas práticas de desenvolvimento

Não possui caráter avaliativo individual.
