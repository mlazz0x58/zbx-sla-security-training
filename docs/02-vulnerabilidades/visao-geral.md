# Visão Geral das Vulnerabilidades Identificadas

Durante o Web Pentest foram identificadas vulnerabilidades classificadas principalmente nas seguintes categorias:

- Broken Access Control
- Tratamento inadequado de erros
- Exposição de informações sensíveis
- Ausência de Rate Limiting em autenticação

Grande parte das falhas decorre de ausência de validações no backend e lacunas no processo de revisão de segurança.
