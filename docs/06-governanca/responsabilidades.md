# Matriz de Responsabilidade (RACI)

| Atividade | Dev | DevOps | Segurança | Tech Lead |
|------------|-----|--------|----------|-----------|
| Validação de Permissões | R |  | C | A |
| Implementação de Rate Limit | R | C | C | A |
| Code Review Segurança | C |  | R | A |
| Reteste Pós-Correção |  |  | R | A |

R = Responsible  
A = Accountable  
C = Consulted  
I = Informed
